# Intuition
We need to check whether the array contains any duplicate number.

# Approach
- Create an empty set to store numbers.
- Traverse the array.
- If a number already exists in the set, return True.
- Otherwise, add the number to the set.
- If no duplicate is found, return False.

# Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)
